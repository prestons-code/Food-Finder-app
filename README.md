# Food Finder

**Food Finder** is a mobile-friendly web application designed to make finding somewhere to eat quick and easy. Whether you know exactly what you're craving or want to try something new, Food Finder helps you discover restaurants near you.

## Features

- **I Know What I Want:** Filter restaurants by meal type, cuisine, and price range.
- **Feeling Lucky:** Automatically generates random filters to help you discover new restaurants.
- **Flexible Location:** Enter a city, ZIP code, or address manually, or use your device's current location.
- **Nearby Restaurants:** Find restaurants within a 20-mile radius of your selected location.
- **Price Filters:** Set a maximum budget of $5, $10, $25, or $50.
- **Directions:** Open restaurant directions directly in Google Maps.
- **Responsive Design:** Optimized for mobile phones, tablets, and desktops.

## Technologies Used

- HTML, CSS, and JavaScript
- OpenStreetMap / Overpass API
- Geolocation API
- Google Maps

## How It Works

1. Choose **I Know What I Want** or **Feeling Lucky**.
2. Enter your location or enable GPS access.
3. Select your filters or generate random preferences.
4. Browse nearby restaurant results.
5. Select a restaurant to open directions.

## Privacy

Food Finder does not automatically access your location. Users can manually enter their location or explicitly grant permission to use their device's GPS.

## Limitations

Restaurant availability and details depend on OpenStreetMap data. Menu prices are not always available, which can limit the accuracy of price-based filtering.
